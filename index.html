Welche Daten werden gespeichert?

Zytra speichert alle Daten ausschließlich lokal auf deinem Gerät. Dazu gehören Zyklusdaten, Symptome, Stimmungseinträge, Einstellungen sowie ein PBKDF2-Hash deiner PIN (kein Klartext). Es werden keine personenbezogenen Daten an externe Server übermittelt.

Was passiert nicht?

  • Keine Übertragung an Server oder Cloud-Dienste
  • Keine Drittanbieter-Analytics oder Tracking
  • Keine Werbung, keine Weitergabe an Dritte
  • Keine Standortdaten, kein Zugriff auf Kontakte oder Kamera

Backup

Die App bietet eine optionale Backup-Funktion. Backups werden nur bei bewusster Nutzeraktion erstellt und an einem Speicherort deiner Wahl auf dem Gerät abgelegt. Die Backup-Datei verlässt dein Gerät nur, wenn du sie aktiv teilst oder überträgst.

Datenlöschung

Alle gespeicherten Daten können jederzeit vollständig gelöscht werden, indem die App deinstalliert wird. Eine manuelle Löschung ist zusätzlich über den Bereich „Einstellungen → Daten zurücksetzen" möglich.

What data is stored?

Zytra stores all data exclusively on your device. This includes cycle data, symptoms, mood entries, settings, and a PBKDF2 hash of your PIN (never in plain text). No personal data is transmitted to external servers.

What does not happen?

  • No transmission to servers or cloud services
  • No third-party analytics or tracking
  • No advertising, no sharing with third parties
  • No location data, no access to contacts or camera

Backup

The app offers an optional backup feature. Backups are created only upon deliberate user action and saved to a storage location of your choice on your device. The backup file only leaves your device if you actively share or transfer it.

Data deletion

All stored data can be permanently deleted at any time by uninstalling the app. Manual deletion is also available via Settings → Reset data.
